What defines the cleaner vibe

  • Offer-first: a pending job offer sits at the top with a live countdown and big Accept / Propose / Decline buttons — their #1 action.
  • One big primary action: "Start job" is a full-width 50px button; the in-job flow (photos → checklist → photos → complete) opens full-screen from here.
  • Get paid, glanceable: this week's earnings always one tap from home.
  • Bigger everything: 44–50px touch targets, generous spacing, single column — built for gloves-and-daylight use.
  • Desktop: same content in a simplified version of the rail shell (cleaners are ~all mobile, so phone is the source of truth).
