# Nexxus Cleaning Platform — Design Context

## Design Context

### Users

Nexxus serves four distinct roles with equal priority:

- **Admins / Business owners** — oversight of the full operation: staff, revenue, bookings, analytics. Desktop-primary, data-rich context.
- **Managers** — day-to-day coordination of cleaners and properties. Mixed desktop/tablet.
- **Cleaners** — checking assigned jobs, routes, and clock-in/out. Mobile-first, task-focused, needs to work quickly in the field.
- **Homeowners** — booking cleanings, tracking appointments, managing their properties. Consumer-grade slicity expected.

Each role sees a scoped view of the same platform. The UI must serve all four without feeling like a compromise.

### Brand Personality

**Modern · Trustworthy · Warm**

Nexxus should feel like a well-run, tech-forward operation — not a legacy enterprise tool, not a generic SaaS dashboard. The golden amber primary (#D9A718) is the key differentiator: it brings warmth and humanity to what could otherwise be a cold field-service tool. Pair it with clean Inter typography and generous whitespace to convey confidence and reliability.

Emotional goal: users should feel **calm and in control** — that nothing will slip, that the system is working for them, that they're running a sharp operation.

### Aesthetic Direction

**Reference:** Airbnb — warm, lifestyle-forward, card-based, image-rich where possible, approachable but polished.

**Theme:** Light mode first. Dark mode is a future enhancement, not a current priority.

**Anti-references to avoid:**

- Generic SaaS admin dashboards (cookie-cutter sidebars, default blue palettes, Bootstrap-era density)
- Cold & corporate — no sterile, ersonal interfaces
- Outdated / legacy enterprise aesthetics

**Visual tone:** Light and airy. Page backgrounds stay `bg-gray-100`, cards are white with soft `border-gray-200` borders and `shadow-sm`. Rounded corners everywhere — `rounded-xl` for cards, `rounded-2xl` for modals, `rounded-full` for badges. Transitions are always `duration-200` to feel snappy without being abrupt.

**Accessibility:** Target WCAG 2.1 AA as a baseline. Ensure sufficient color contrast on amber backgrounds (use `text-white` on `primary-600` buttons, `text-primary-900` on light amber tints). Support keyboard navigation and screen readers without sacrificing visual design.

### Tech Stack (for reference in design decisions)

- **Framework:** Next.js 16 (App Router), React 19, TypeScript 5
- **Styling:** Tailwind CSS 3.4 — all UI is handcrafted, no external component library (no Shadcn, Radix, MUI)
- **Icons:** Lucide React
- **Charts:** Recharts
- **Fonts:** Inter (Google Fonts, 300–900 weight range)
- **Color system:** Custom Tailwind tokens — `primary-*` (golden amber), `secondary-*` (slate gray), `success-*` (green)

### Typography

- **Family:** Inter — clean, modern, highly legible at all weights
- **Scale:** `text-xs` (metadata/labels) → `text-sm` (body) → `text-lg font-semibold` (card titles) → `text-xl font-bold` (section headings) → `text-2xl–3xl font-bold` (logo/page titles)
- **Tracking:** Use `uppercase tracking-wide` on `text-xs` labels for visual structure

### Design Principles

1. **Warm professionalism** — golden amber is the soul of the brand. Use it consistently on interactive elements, active states, and key data points. Never let the UI feel cold or generic.

2. **Clarity over density** — every screen should communicate one primary purpose. Resist the temptation to surface everything at once. Use progressive disclosure (modals, drawers, expandable cards) to manage complexity.

3. **Role-appropriate focus** — the cleaner's view is task-first and mobile-optimized; the admin's view is data-rich and analytics-forward. Design for the context in which each role actually uses the platform.

4. **Trustworthy consistency** — use the same card, badge, button, and modal patterns everywhere. Primary actions should consistently use the cleaner "Start Job" button treatment (gold wash gradient + primary border chrome) so users can instantly recognize the main action.

5. **Light and airy** — generous whitespace, `bg-gray-50` page backgrounds, white cards, soft shadows. The interface should breathe. When in doubt, add more space rather than less.
